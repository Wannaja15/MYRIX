# MYRIX

Paket GitHub Pages untuk proyek MYRIX.

## Isi
- `index.html` — aplikasi MYRIX versi KUALITAS GERAK FIX V2, dengan tautan favicon ke `assets/logo.png`.
- `logo.png` dan `assets/logo.png` — logo MYRIX yang dikirim di percakapan.

## GitHub Pages
1. Unggah isi ZIP ini ke root repository GitHub.
2. Pastikan file utama bernama `index.html`.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.

Catatan: paket ini untuk website/repository, bukan APK yang dapat langsung dipasang. Uji kembali impor media, penyimpanan proyek, dan ekspor video setelah dipublikasikan.
